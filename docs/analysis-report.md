# Hillstrom 邮件营销随机实验分析

## 1. 用随机分配建立自然消费基准

发邮件后产生的销售包含即使不发邮件也会发生的购买。为了估计邮件的贡献，Kevin Hillstrom 公开了一个零售商的三组随机实验。实验从过去一年买过商品的 64,000 人中分配男装邮件、女装邮件及不发邮件三个方案，跟踪随后两周。[原始挑战](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html)

原 CSV 一行一客户，12 列无缺失。8 个实验前特征用于检查可比性和探索异质性，segment 是分配方案，visit、conversion 和 spend 是实验后结果。[数据字典](data-dictionary.md)

| 基线指标 | 男装邮件 | 女装邮件 | 不发邮件 |
| --- | ---: | ---: | ---: |
| 人数（占比） | 21,307（33.29%） | 21,387（33.42%） | 21,306（33.29%） |
| 历史平均消费（美元） | 242.84 | 242.54 | 240.88 |
| 距上次购买（月） | 5.77 | 5.77 | 5.75 |
| 新客户占比 | 50.15% | 50.32% | 50.20% |
| 买过男装 | 55.09% | 54.89% | 55.32% |
| 买过女装 | 55.14% | 55.01% | 54.76% |
| 多渠道 / 电话 / 网站占比（%） | 12.09 / 43.37 / 44.54 | 12.06 / 44.20 / 43.74 | 12.23 / 43.78 / 43.99 |
| 乡村 / 郊区 / 城市占比（%） | 15.22 / 44.59 / 40.19 | 14.87 / 45.12 / 40.01 | 14.73 / 45.18 / 40.09 |

七档历史消费的组内分布也接近。历史购买品类可以重叠，比例需分别计算。描述性平衡符合随机分配的预期，有限样本允许基线波动。若按既有偏好决定发哪封邮件，原有消费倾向就会与方案混在一起。因果解释依赖随机分配正确实施、结果记录可比和客户之间无干预溢出。后续比较以分配为准，估计分配到方案的平均效果（ITT）。

## 2. 从到访到购买，再到每名客户的收入

访问率衡量两周内是否到访网站，原表没有邮件打开、点击或访问次数。访问率和购买率都用全组随机分配人数作分母。若只算访客的转化率，分母会受干预影响，回答的也变成访客中有多少人购买。

| 指标 | 男装邮件 | 女装邮件 | 不发邮件 |
| --- | ---: | ---: | ---: |
| 访问人数 / 访问率 | 3,894 / 18.28% | 3,238 / 15.14% | 2,262 / 10.62% |
| 购买人数 / 购买率 | 267 / 1.25% | 189 / 0.88% | 122 / 0.57% |
| 销售额（美元） | 30,311.69 | 23,038.11 | 13,908.33 |
| RPC（美元/客户） | 1.4226 | 1.0772 | 0.6528 |
| 购买者平均消费（美元） | 113.53 | 121.89 | 114.00 |

总销售额受组规模影响，RPC 把零消费客户也计入分母，直接比较每名随机分配客户的平均收入。此处 RPC 等于购买率乘以购买者平均消费。男装组购买率较高，尽管其购买者平均花费低于女装组，整体 RPC 仍较高。购买者由实验后结果筛选，条件均值只能描述收入构成。相对不发邮件，两种邮件的访问率增加 7.66 和 4.52 个百分点，购买率增加 0.68 和 0.31 个百分点，RPC 增加 $0.7698 和 $0.4244。点估计有多稳定，需要进一步检验。

## 3. 衡量组间差异与不确定性

重新随机分配客户时，即使平均处理效果相同，组间差也会波动。访问与购买是二元结果，用双侧双样本比例 Z 检验和 Newcombe 差值区间。消费大量为零且右偏，但业务关心的是平均销售额。Welch t 检验容许组间方差不同，并利用大样本下均值差的近似抽样分布。为检查区间对估计方法的敏感性，再分别在每组内以原样本量有放回抽取客户，重复 3,000 次，取均值差的 2.5% 和 97.5% 分位数。

三组两两比较后，偶然出现较小 P 值的机会增加。先对每个指标内的三项检验做 Holm 校正，再将九项比较放在同一检验族校正。下表区间是未经同时调整的单项 95% 区间，行为指标以百分点计，RPC 以美元/客户计。

| 指标 | 前者减后者 | 差异 | 单项 95% 区间 | 原始 P | 指标内 Holm P | 九项 Holm P |
| --- | --- | ---: | --- | ---: | ---: | ---: |
| 访问 | 男装－不发 | 7.6590 | [7.00, 8.32] | 5.69e−112 | 1.71e−111 | 5.12e−111 |
| 访问 | 女装－不发 | 4.5233 | [3.89, 5.16] | 3.18e−44 | 6.36e−44 | 2.55e−43 |
| 访问 | 男装－女装 | 3.1356 | [2.43, 3.84] | 3.80e−18 | 3.80e−18 | 2.66e−17 |
| 购买 | 男装－不发 | 0.6805 | [0.5014, 0.8641] | 1.52e−13 | 4.57e−13 | 9.14e−13 |
| 购买 | 女装－不发 | 0.3111 | [0.1502, 0.4745] | 0.000157 | 0.000314 | 0.000628 |
| 购买 | 男装－女装 | 0.3694 | [0.1746, 0.5663] | 0.000205 | 0.000314 | 0.000628 |
| RPC | 男装－不发 | 0.7698 | [0.4851, 1.0545] | 1.16e−7 | 3.49e−7 | 5.82e−7 |
| RPC | 女装－不发 | 0.4244 | [0.1690, 0.6799] | 0.001129 | 0.002259 | 0.002259 |
| RPC | 男装－女装 | 0.3454 | [0.0326, 0.6583] | 0.030469 | 0.030469 | 0.030469 |

RPC Bootstrap 区间依次为 [0.4807, 1.0461]、[0.1877, 0.6902]、[0.0344, 0.6582]，与 Welch 的方向和宽度接近。统一校正后九项均低于 0.05。男装相对女装的收入证据较弱，区间下限接近每客户三美分。P 值衡量零差异假设下出现同等或更极端统计量的概率，经营上还需判断差异是否足以覆盖成本。

## 4. 在明确假设下估计经济价值

男装组约 $1.42 的 RPC 包含约 $0.65 的自然收入基线。若未来 10 万名客户与历史受试人群可比，且两周平均效果可迁移，男装与女装邮件预计增加 $76,982.72 和 $42,441.22 的销售额。将单项 Welch 区间同样乘以人数，得到约 $48,514–$105,452 和 $16,896–$67,987。

数据缺少真实毛益率和营销成本。设贡献毛益率为 m、单位营销成本为 c，假设增量利润等于人数乘以「m × 增量 RPC − c」。暂不计固定成本。在 30% 毛益率、每客 $0.10 成本时，男装和女装的人均增量利润分别为 $0.1309、$0.0273。使点估计利润为零的单位成本分别为 $0.2309 和 $0.1273。

| ---: | ---: | ---: | ---: |
| 20% | 0.10 | 5,396.54 | −1,511.76 |
| 20% | 0.20 | −4,603.46 | −11,511.76 |
| 30% | 0.10 | 13,094.81 | 2,732.37 |
| 30% | 0.20 | 3,094.81 | −7,267.63 |
| 40% | 0.10 | 20,793.09 | 6,976.49 |
| 40% | 0.20 | 10,793.09 | −3,023.51 |

固定 30% 毛益率，将 RPC Welch 区间两端代入利润公式。

| 假设单位成本（美元） | 男装单项 95% 利润区间（美元） | 女装单项 95% 利润区间（美元） |
| ---: | ---: | ---: |
| 0.10 | [4,554.19, 21,635.44] | [−4,931.30, 10,396.03] |
| 0.20 | [−5,445.81, 11,635.44] | [−14,931.30, 396.03] |

成本为 $0.10 时男装区间全正，女装虽有正点估计但跨零。成本升至 $0.20 时男装也跨零。区间只反映历史平均效果的统计不确定性，成本、毛益和市场变化需另行评估。

## 5. 检查异质性并评价固定投放规则

总体均值有可能掩盖客户差异。用实验前 mens、womens 划出三个互斥群体，对照基准取各群体自身的不发邮件组。

| 历史购买 | 男装 / 女装 / 不发人数 | 对照 RPC | 男装增量 | 女装增量 | 男装减女装 |
| --- | --- | ---: | ---: | ---: | ---: |
| 仅男装 | 9,558 / 9,622 / 9,638 | 0.6954 | 0.6827 | 0.2784 | 0.4044 |
| 仅女装 | 9,568 / 9,647 / 9,519 | 0.4906 | 0.6157 | 0.6316 | −0.0159 |
| 两类都买 | 2,181 / 2,118 / 2,149 | 1.1801 | 1.8250 | 0.1619 | 1.6631 |

仅买过女装的客户两封邮件几乎持平。两类都买组的男装增量最高，但组内 2,181 名男装邮件客户只有 53 名购买，少数消费记录可能明显影响均值。要判断效果是否随群体改变，需要直接比较各群体的方案差。分别查看各分群是否显著无法回答这个问题。

使用含方案、群体和交互项的 OLS，以 HC3 稳健协方差做联合 Wald 检验。三方案整体检验问两种邮件相对对照的效果是否随品类变化，4 个约束，P = 0.1418。仅保留两种邮件后，检验问两封邮件的相对差是否随品类变化，2 个约束，P = 0.0417。后者是探索性的名义 P 值。即使交互存在，也可能只是同一邮件在各群体中的优势幅度不同，改变投放的实际价值还需直接估计。

### 5.4 统一策略 A 与分群策略 B

在挑出最高均值的样本上评价规则，容易高估策略价值。用种子 42 拆出 70% 训练客户，留下 19,200 人作内部评价。A 从三方案选训练集总体 RPC 最高的一种，男装、女装、不发分别为 1.3732、1.0529、0.5961，故 A 统一发男装。B 在每个群体内分别选训练 RPC 最高的方案。

| 历史购买 | 训练 RPC（男装 / 女装 / 不发） | B 选择 | 验证 RPC（男装 / 女装 / 不发） | 验证权重 |
| --- | --- | --- | --- | ---: |
| 仅男装 | 1.2746 / 0.9876 / 0.5693 | 男装 | 1.6214 / 0.9410 / 0.9960 | 44.55% |
| 仅女装 | 1.0222 / 1.0346 / 0.5134 | 女装 | 1.2992 / 1.3227 / 0.4370 | 45.23% |
| 两类都买 | 3.3143 / 1.4392 / 1.0931 | 男装 | 2.2542 / 1.1250 / 1.3719 | 10.22% |

固定规则后，按验证集原始随机分配计算每个群体对应方案的均值，再按群体占比加权。A 和 B 的估计 RPC 分别为 $1.5403 和 $1.5510。只有仅买女装组换邮件，Welch 检验比较该群体验证集中的两组独立客户，女装相对男装约多 $0.0235，P = 0.9571。用验证权重缩放差值和区间，B−A 为 +$0.0106，单项 95% 区间 [−$0.3757, $0.3969]。权重按固定值处理。

按点估计，10 万名可比客户约多 $1,061 销售额，30% 毛益对应约 $318 额外贡献，个性化运营成本还未扣除。区间允许正负结果，缺少用分群替代统一方案的可靠证据。此前已探索全量数据，这次划分只支持探索性内部评价。

| 非近一年新增 | 31,856 | 0.5780 | 0.1140 |
| 近一年新增 | 32,144 | 0.9600 | 0.7323 |

两个特征分别与三方案建模，用 HC3 检验联合交互项。newbie 的原始 P = 0.051584，两项 Holm 后为 0.103168。channel 的原始及校正 P 均为 0.315287。新客户、多渠道客户的点估计较高，当前证据不足以用它们划定优先投放人群。非显著结果也保留了下一次试点的备选假设，现有数据仍允许真实的群体差异。

## 经营建议与范围

将统一男装邮件作为新随机试点的优先候选，保留不发邮件组，并用真实毛益和营销成本判断是否值得推广。个性化规则可作为另一个事先固定的试验组，直接检验相对统一方案的额外价值。2008 年样本来自已有购买客户，观察期只有两周，长期复购、退订和当前市场响应仍待新数据评估。[复现与审计记录](verification.md)
