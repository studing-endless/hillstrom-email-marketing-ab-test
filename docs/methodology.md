# 统计口径

- 按原随机分配汇总全部客户。行为率为二元结果均值，RPC 为消费均值。对照差估计分配方案的平均增量。
- 二元指标采用双侧比例 Z 检验和 Newcombe 差值区间。RPC 采用不等方差 Welch 双侧检验和 Welch–Satterthwaite 区间，另用种子 42 逐组重抽样 3,000 次计算百分位区间。
- Holm 分别应用于单指标三项、统一九项和第 5.5 节两项检验族。所有区间为未同时调整的单项 95% 区间。
- 交互检验用 OLS 拟合方案、群体及乘积项，以 HC3 协方差做联合 Wald 检验。品类整体和仅邮件的 P 值按探索性原始值报告。
- 策略验证按群体占比加权随机实验单元格均值。对变化群体使用独立单元格均值的加权方差与 Satterthwaite 自由度，相同方案群体抵消。单变化群体时退化为原 Welch 的权重换算。权重视为固定。

## 多重比较的检验族

| 范围 | 原假设 | 报告口径 |
| --- | --- | --- |
| 单指标三项 | 该指标的男装−不发、女装−不发、男装−女装总体差值分别为零 | 3 个原始 P 共同 Holm |
| 三指标九项 | visit、conversion、spend 各自上述三个假设 | 9 个原始 P 共同 Holm，作为跨指标结果判断依据 |
| 第 5.5 节两项 | 新老客户无方案交互；历史渠道无方案交互 | 两项联合 Wald 原始 P 共同 Holm |
| 第 5.3 节品类 | 三方案无品类交互；两封邮件无品类交互 | 探索性原始 P，未做项目级统一校正 |

前两个范围是同一组比较的两种声明范围，不应把两套调整值再混合校正。第 5.5 节单列是围绕两个特征的有限探索问题，其错误率控制只覆盖这两个假设。历史品类、其他历史探索和新增单项 Bootstrap 区间均未被这一校正覆盖。分开报告允许读者识别研究问题，但不能据此声称所有探索的家族错误率都受控。

所有单项 95% 区间均未经过 Holm 同时校正。新增五项 Bootstrap 对比完整报告，作为有条件的敏感性描述，不作为确认性个性化效果结论。[诊断与敏感性细节](statistical-quality.md)
