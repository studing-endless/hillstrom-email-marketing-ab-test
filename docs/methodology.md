# 统计口径

- 按原随机分配汇总全部客户。行为率为二元结果均值，RPC 为消费均值。对照差估计分配方案的平均增量。
- 二元指标采用双侧比例 Z 检验和 Newcombe 差值区间。RPC 采用不等方差 Welch 双侧检验和 Welch–Satterthwaite 区间，另用种子 42 逐组重抽样 3,000 次计算百分位区间。
- Holm 分别应用于单指标三项、统一九项和第 5.5 节两项检验族。所有区间为未同时调整的单项 95% 区间。
- 交互检验用 OLS 拟合方案、群体及乘积项，以 HC3 协方差做联合 Wald 检验。品类整体和仅邮件的 P 值按探索性原始值报告。
- 策略验证按群体占比加权随机实验单元格均值。只有一个变更群体时，整体差值和区间为该群体两方案差值与区间乘其权重，权重视为固定。
