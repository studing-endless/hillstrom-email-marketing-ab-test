# Hillstrom 邮件营销随机实验分析

零售商要做三个决定：发不发邮件、发哪封、给谁发。三者都绕不开同一个问题：邮件组的购买中，有多少即使不发也会发生？Kevin Hillstrom 公开的实验将过去一年购买过商品的 64,000 名客户随机分配到男装邮件、女装邮件和不发邮件三个方案，观察随后两周。这个设计让我们先估计邮件增加了什么，再判断增加的收入是否值得投入，以及按客户分群能否创造额外价值。[原始挑战](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html)

## 1. 谁收到邮件，决定了销售差异能否归因

假设零售商按偏好发邮件，把本来就有较强购买意愿的客户集中分给男装邮件，把近期很少购物的人留在对照组。即使邮件毫无作用，男装组也可能卖得更多。原有购买意愿同时影响方案分配和购买结果，两种影响混在一起。随机分配让仅买过男装的客户也可能收到女装邮件或不收到邮件。对照组由此提供自然购买的基准，同一类客户接受不同方案的记录也为后面的分群比较提供了依据。

正式比较之前，先检查字段类型、缺失和组规模。原 CSV 一行一客户，12 列无缺失。8 个实验前特征描述客户原来的状态，`segment` 记录分配方案，`visit`、`conversion` 和 `spend` 记录两周结果。三组人数接近只说明分配规模接近，仍需检查是否有某一组明显集中着高消费或更活跃的客户。因此同时看历史消费均值与七档分布，分类特征用组内占比比较。[数据字典](data-dictionary.md)

| 基线指标 | 男装邮件 | 女装邮件 | 不发邮件 |
| --- | ---: | ---: | ---: |
| 人数（占比） | 21,307（33.29%） | 21,387（33.42%） | 21,306（33.29%） |
| 历史平均消费（美元） | 242.84 | 242.54 | 240.88 |
| 距上次购买（月） | 5.77 | 5.77 | 5.75 |
| 新客户占比 | 50.15% | 50.32% | 50.20% |
| 买过男装 | 55.09% | 54.89% | 55.32% |
| 买过女装 | 55.14% | 55.01% | 54.76% |
| 多渠道 / 电话 / 网站占比（%） | 12.09 / 43.37 / 44.54 | 12.06 / 44.20 / 43.74 | 12.23 / 43.78 / 43.99 |
| 乡村 / 郊区 / 城市占比（%） | 15.22 / 44.59 / 40.19 | 14.87 / 45.12 / 40.01 | 14.73 / 45.18 / 40.09 |

三组历史消费、购买间隔和新老客户构成接近，七档历史消费分布及渠道、地区构成也相近。历史男装和女装购买可以重叠，因此分别计算占比。这些是描述性检查，与随机化的预期一致。有限样本仍会波动，平均因果解释依靠正确实施的随机分配、可比的结果记录和客户间无干预溢出。接下来按原始分配比较结果，估计分配到各方案的平均效果（ITT）。

## 2. 流量和购买增加以后，收入发生了什么

先问邮件是否让更多客户访问网站，再问增加的访问是否伴随更多客户购买。访问指两周内至少到访一次，原表没有打开、点击和访问次数。两个比例都除以全组分配人数，因为决策是把一名客户分到哪个方案。只用访客做分母，会把比较限定在一个可能已被邮件改变的人群。

购买率仍无法决定收入排序。举例说，同样覆盖 1,000 人，30 人购买可以共消费 1,500 美元，20 人购买也可以共消费 2,000 美元。总销售额还会随实验组人数改变，因此比较方案用每名分配客户的收入（RPC），把零消费客户纳入分母。下表把两项行为和两个收入分量放在一起，便于追踪差异来自哪里。

| 指标 | 男装邮件 | 女装邮件 | 不发邮件 |
| --- | ---: | ---: | ---: |
| 访问人数 / 访问率 | 3,894 / 18.28% | 3,238 / 15.14% | 2,262 / 10.62% |
| 购买人数 / 购买率 | 267 / 1.25% | 189 / 0.88% | 122 / 0.57% |
| 销售额（美元） | 30,311.69 | 23,038.11 | 13,908.33 |
| RPC（美元/客户） | 1.4226 | 1.0772 | 0.6528 |
| 购买者平均消费（美元） | 113.53 | 121.89 | 114.00 |

相对不发邮件，男装和女装访问率分别高 7.66 和 4.52 个百分点，购买率高 0.68 和 0.31 个百分点。此处 RPC 等于购买率乘以购买者平均消费。女装邮件组的购买者花费较高，男装邮件组的购买率优势仍使其 RPC 最高。购买者由实验后的结果筛选，这一条件均值只能描述收入构成，无法据此归因于邮件让购买者花得更多。

两封邮件相对不发的 RPC 点估计分别增加 $0.7698 和 $0.4244。若要据此选一封邮件，接下来需要看这些差异相对于随机波动有多大，也要直接比较两封邮件。

## 3. 观察到的优势有多稳定

即使两组总体结果相同，随机分配后也可能观察到均值差。检验衡量零差异假设下出现同等或更极端统计量的概率，区间则给出效应可能处于怎样的量级。两封邮件分别优于不发，只回答了各自的对照比较。判断哪封更好，需要直接比较男装与女装。所有比较都用双侧检验，容许差异朝任一方向出现。

访问与购买是二元结果，用双样本比例 Z 检验和 Newcombe 差值区间。消费有大量零值，少数购买者花费较高，组间方差也可能不同。由于关心的是每名客户的平均收入，使用允许不等方差的 Welch t 检验，利用大样本下均值差的抽样分布近似。为检查区间是否依赖这一近似，再在各组按原样本量有放回重抽样 3,000 次，以均值差的 2.5% 和 97.5% 分位数得到 Bootstrap 区间。

每项指标有三次比较，逐项用 0.05 会增加至少一次错误拒绝的风险，因此先在指标内用 Holm 校正。报告同时引用三项指标时，再把九个原始 P 值放入同一检验族校正。下表并列展示两种校正范围。区间是未做同时调整的单项 95% 区间，行为指标以百分点计，RPC 以美元/客户计。

| 指标 | 前者减后者 | 差异 | 单项 95% 区间 | 原始 P | 指标内 Holm P | 九项 Holm P |
| --- | --- | ---: | --- | ---: | ---: | ---: |
| 访问 | 男装－不发 | 7.6590 | [7.00, 8.32] | 5.69e−112 | 1.71e−111 | 5.12e−111 |
| 访问 | 女装－不发 | 4.5233 | [3.89, 5.16] | 3.18e−44 | 6.36e−44 | 2.55e−43 |
| 访问 | 男装－女装 | 3.1356 | [2.43, 3.84] | 3.80e−18 | 3.80e−18 | 2.66e−17 |
| 购买 | 男装－不发 | 0.6805 | [0.5014, 0.8641] | 1.52e−13 | 4.57e−13 | 9.14e−13 |
| 购买 | 女装－不发 | 0.3111 | [0.1502, 0.4745] | 0.000157 | 0.000314 | 0.000628 |
| 购买 | 男装－女装 | 0.3694 | [0.1746, 0.5663] | 0.000205 | 0.000314 | 0.000628 |
| RPC | 男装－不发 | 0.7698 | [0.4851, 1.0545] | 1.16e−7 | 3.49e−7 | 5.82e−7 |
| RPC | 女装－不发 | 0.4244 | [0.1690, 0.6799] | 0.001129 | 0.002259 | 0.002259 |
| RPC | 男装－女装 | 0.3454 | [0.0326, 0.6583] | 0.030469 | 0.030469 | 0.030469 |

九项统一校正后仍低于 0.05。按表中三项 RPC 的顺序，Bootstrap 区间为 [0.4807, 1.0461]、[0.1877, 0.6902]、[0.0344, 0.6582]，与 Welch 的方向和宽度接近。两封邮件都显示正向收入增量，男装相对女装的证据较弱，区间下限仅约每客三美分。选定投放方案还要回答另一个问题：这些额外收入能否覆盖支出？

## 4. 哪些成本条件下值得发邮件

男装组每客约 $1.42 的收入包含不发也会产生的约 $0.65。用对照差外推，在 10 万名可比客户、历史两周平均效果可迁移的假设下，男装与女装增量销售额分别为 $76,982.72 和 $42,441.22。将单项 Welch 区间也乘以人数，得到约 $48,514–$105,452 和 $16,896–$67,987。这里外推的是群体平均增量。

额外销售先扣除销售相关的可变成本，剩下贡献毛益，再扣除营销成本。由于数据没有实际毛益和营销费用，只做情景测算。以贡献毛益率 m、每客营销成本 c 表示，增量利润等于人数乘以「m × 增量 RPC − c」，暂不计固定成本。若毛益率为 30%、每客成本为 $0.10，两封邮件的人均利润点估计分别为 $0.1309 和 $0.0273。把利润设为零反推预算，点估计的每客盈亏平衡成本分别是 $0.2309 和 $0.1273。

为判断财务报价变化会不会改变选择，固定 10 万名客户，比较三种假设毛益率和两种单位成本。

| 假设毛益率 | 假设单位成本（美元） | 男装利润（美元） | 女装利润（美元） |
| ---: | ---: | ---: | ---: |
| 20% | 0.10 | 5,396.54 | −1,511.76 |
| 20% | 0.20 | −4,603.46 | −11,511.76 |
| 30% | 0.10 | 13,094.81 | 2,732.37 |
| 30% | 0.20 | 3,094.81 | −7,267.63 |
| 40% | 0.10 | 20,793.09 | 6,976.49 |
| 40% | 0.20 | 10,793.09 | −3,023.51 |

在 20% 毛益率、$0.20 成本下，两封邮件的利润点估计均为负。若毛益率为 30%，成本从 $0.10 升至 $0.20，男装点估计仍为正，女装则由正转负。点估计只能给出情景排序，还需要看历史效果估计的波动是否足以改变盈亏判断。为此固定 30% 毛益率，把 RPC 的 Welch 区间两端分别代入利润公式。

| 假设单位成本（美元） | 男装单项 95% 利润区间（美元） | 女装单项 95% 利润区间（美元） |
| ---: | ---: | ---: |
| 0.10 | [4,554.19, 21,635.44] | [−4,931.30, 10,396.03] |
| 0.20 | [−5,445.81, 11,635.44] | [−14,931.30, 396.03] |

每客 $0.10 时，男装利润区间全正，女装跨零。每客 $0.20 时，男装虽仍有正点估计，区间也跨零。跨零表示现有估计允许盈利或亏损，无法从区间读出亏损概率。区间只传播历史平均效果的统计误差，真实成本、毛益及市场变化仍需另行判断。这一步给出了优先测试的统一方案，接下来才问是否值得为某些客户换邮件。

## 5. 哪些客户值得换一封邮件

### 5.1–5.3 从分群点估计到交互检验

历史购买品类与邮件内容直接相关，而且投放前已知，因此先按 `mens`、`womens` 分成仅男装、仅女装和两类都买三个互斥群体。每个群体用自己的不发邮件组估计自然收入，避免把本来就消费较多误解为邮件增量更大。下表同时列出人数和效果，以便识别哪些差异来自样本较小的群体。

| 历史购买 | 男装 / 女装 / 不发人数 | 对照 RPC | 男装增量 | 女装增量 | 男装减女装 |
| --- | --- | ---: | ---: | ---: | ---: |
| 仅男装 | 9,558 / 9,622 / 9,638 | 0.6954 | 0.6827 | 0.2784 | 0.4044 |
| 仅女装 | 9,568 / 9,647 / 9,519 | 0.4906 | 0.6157 | 0.6316 | −0.0159 |
| 两类都买 | 2,181 / 2,118 / 2,149 | 1.1801 | 1.8250 | 0.1619 | 1.6631 |

仅买过女装的客户两封邮件表现接近。两类都买的群体男装增量最高，但男装邮件组 2,181 人中只有 53 人购买，少数消费记录可能显著影响均值。要判断各群体的效果是否真有差异，需要检验方案差会不会随群体改变。例如两个群体原本消费水平不同，若男装都比女装高同样金额，这两个群体的邮件相对效果仍相同。

用包含方案、历史品类及交互项的 OLS，以 HC3 稳健协方差做联合 Wald 检验。三方案整体检验比较两种邮件相对不发的增量是否随品类变化，4 个约束，P = 0.1418，证据不足。仅保留两封邮件后，检验的是两者的相对差是否随品类变化，2 个约束，P = 0.0417。这是探索性的名义 P 值。即使某封邮件的优势幅度随群体而变，也只有策略实际换了方案的群体才会产生额外收入，因此还要直接评价投放规则。

### 5.4 用同一实验评价两条固定规则

在同一批客户中挑出最高均值，再用这个均值评价规则，容易把随机偏高当成策略收益。以种子 42 划出 70% 的训练样本，剩余 19,200 人用于内部评价。同一份训练数据产生两条规则，候选动作均为男装、女装或不发邮件。

- **A 统一投放。** 按训练集总体 RPC 选一个方案。男装、女装和不发分别为 1.3732、1.0529 和 0.5961，因此 A 统一选男装。
- **B 按品类投放。** 在每个品类的训练客户中分别选 RPC 最高的方案。训练列决定下表的 B 选择，验证列只用于评价已经固定的选择。

| 历史购买 | 训练 RPC（男装 / 女装 / 不发） | B 选择 | 验证 RPC（男装 / 女装 / 不发） | 验证权重 |
| --- | --- | --- | --- | ---: |
| 仅男装 | 1.2746 / 0.9876 / 0.5693 | 男装 | 1.6214 / 0.9410 / 0.9960 | 44.55% |
| 仅女装 | 1.0222 / 1.0346 / 0.5134 | 女装 | 1.2992 / 1.3227 / 0.4370 | 45.23% |
| 两类都买 | 3.3143 / 1.4392 / 1.0931 | 男装 | 2.2542 / 1.1250 / 1.3719 | 10.22% |

验证时沿用客户在历史实验中的分配。对每个品类，A 使用验证集中原来分到男装组的平均消费。B 也使用同一批验证数据，但对仅买过女装的客户取原来分到女装组的均值。两条规则都按验证集的群体占比加权，因为要估计的是服务同一客户组合时的平均收入。得到 A 为 $1.5403，B 为 $1.5510。

其余两个品类使用同一方案，做差时抵消。因此用 Welch 比较仅买过女装的验证客户中、原来分到两种邮件的两组不同客户。女装相对男装的组内差约 $0.0235，P = 0.9571。将差值及区间乘该群体约 45.23% 的固定权重，得到整体 B−A 为 +$0.0106，单项 95% 区间 [−$0.3757, $0.3969]。

如果按点估计外推到 10 万名可比客户，额外销售约 $1,061，按 30% 毛益率约增加 $318 贡献毛益，尚未扣除个性化运营成本。区间允许正负结果，当前缺少用 B 替代 A 的可靠证据。此前已查看全量数据，拆分只能作为探索性内部评价。

### 5.5 新老身份和历史渠道能否指导投放

购买品类只覆盖一种定向思路。接着检查新老客户是否对邮件有不同的增量响应，以及过去通过电话、网站或多渠道购物的客户是否有不同响应。两项信息都在邮件发送前已知，历史渠道描述客户过去如何购买。先比较各特征水平内的样本量和相对自身对照组的增量，再判断效果差是否随特征变化。

| 客户特征 | 人数 | 男装增量 RPC | 女装增量 RPC |
| --- | ---: | ---: | ---: |
| 非近一年新增 | 31,856 | 0.5780 | 0.1140 |
| 近一年新增 | 32,144 | 0.9600 | 0.7323 |
| 多渠道 | 7,762 | 1.2091 | 1.1575 |
| 电话 | 28,021 | 0.5641 | 0.2325 |
| 网站 | 28,217 | 0.8504 | 0.4163 |

新客户、多渠道客户的增量点估计较高。分别以 HC3 联合检验两个特征与三方案的交互，再对两项 P 值做 Holm 校正。新老身份的 P 值从 0.051584 调整为 0.103168，历史渠道原始和校正 P 值均为 0.315287。现有数据不足以支持按这两项特征优先投放，也不足以判定各群体的效果等同。

## 经营建议与范围

把统一男装邮件作为新随机试点的优先候选，保留不发邮件组，结合真实贡献毛益与投放成本决定是否推广。若要继续研究个性化，先固定分群规则，再在新数据中直接比较它相对统一方案带来的增量。这个判断来自 2008 年既有客户的两周结果，长期复购、退订与当前市场响应需要新数据。[复现与审计记录](verification.md)
